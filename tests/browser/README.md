# Браузерные проверки (необязательны для запуска презентации)

Все скрипты запускают Chromium. **В окружении без видеокарты рендер программный (SwiftShader):
FPS из этих прогонов не отражает реальное железо.** Годятся для: ошибок консоли, 404, шейдеров, утечек, камеры,
сравнений «до/после» на одной машине. Реальный FPS — только `index.html?bench` в обычном браузере.

| Скрипт | Язык | Что делает |
|---|---|---|
| `audit.py` | Python | приёмочный аудит Phase 1.5 (25+ проверок): старт, сеть, ассеты, шейдеры и защита, камера, dispose, циклы, переходы, потеря контекста |
| `perf.py` | Python | длительный замер кадров (`--seconds 60 --query "?scene=sandbox&noadapt&pr=1"`) |
| `ablation.py` | Python | стоимость кадра по компонентам сцены (на замороженном кадре) |
| `repro_phase1_issues.py` | Python | воспроизведение заявленных после Phase 1 проблем на временной копии с возвращёнными дефектами |
| `prep-audit.cjs` | Node | независимый аудит из архива prep (другая сессия): консоль, 404, 60 с, 8 перезапусков, камера |

Установка: `pip install playwright && playwright install chromium` (для Python) либо `npm i -D playwright && npx playwright install chromium` (для Node).
Результаты последнего прогона лежат в `docs/phase1.5/*.json`.
