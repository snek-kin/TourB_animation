# 02 · Архитектура и техническое решение

## Решения и причины

| Решение | Почему |
|---|---|
| Без сборщика: `index.html` + ES-модули + import map | вы запускаете в VS Code (Live Server); `npm install` не нужен |
| three **r187** и gsap **3.15.1** лежат в `vendor/` (скопированы `tools/vendor.mjs`) | презентация работает офлайн — на защите интернет может не быть; версии зафиксированы |
| GSAP подключён классическим `<script>`, в модулях — `core/gsap.js` | у gsap нет готового браузерного ES-бандла под import map; так проще всего |
| Нет TypeScript | меньше инструментов; JSDoc-комментарии у ключевых API |
| Нет постобработки (bloom) в Phase 1 | брифом требуется «без чрезмерного свечения»; дешёвое свечение — аддитивные спрайты. Bloom подключается в Phase 2–3 при необходимости |
| Нет KTX2 пока | для VRAM полезен, но требует транскодера Basis; добавим, когда появятся тяжёлые текстуры |

## Модули (`src/core/`)

| Модуль | Ответственность |
|---|---|
| `App` | рендерер, цикл, ресайз с сохранением 16:9, **адаптивное разрешение** (если средний FPS < 50 — pixelRatio × 0.85, не ниже 0.75), клавиши, глобальные ошибки, потеря WebGL-контекста |
| `SceneManager` | порядок сцен, автопереход по таймеру, пауза, `seek(t)`, **фоновая предзагрузка следующей сцены**, освобождение предыдущей |
| `BaseScene` | жизненный цикл `preload → build → enter → update → lateUpdate → exit → dispose`, мастер-таймлайн, `track()` для очистки |
| `CameraController` | камера на рельсе (Catmull-Rom), сглаживание, без крена, мин. высота над рельефом, выталкивание из AABB-коллайдеров |
| `AssetManager` | загрузка по `assets.manifest.json`: GLB (+Draco), текстуры, аудио, JSON; кэш; дедупликация; **отсутствующий ассет не ломает сцену** |
| `TransitionManager` | реестр переходов: `cut`, `dip`; `matchCut` — контракт готов, реализация в Phase 2 |
| `AudioManager` | Web Audio, разблокировка по клику, fade, mute; без файлов молча ничего не делает |
| `Hud` (`ui/`) | загрузчик, бейдж статуса функции, субтитры, отладка, окно ошибки |
| `Disposer` | освобождение GPU-памяти; кэшированные ассеты (`userData.shared`) не трогает |

## Модель времени (важно для кинематографа)

Каждая сцена имеет **мастер-таймлайн GSAP на паузе**; `SceneManager` каждый кадр ставит
`timeline.time(scene.elapsed)`. Камера — часть этого таймлайна (`cameraCtl.addToTimeline`). Поэтому:

- пауза, перемотка (`tourb.scenes.seek(12)` в консоли) и будущая покадровая запись **детерминированы**;
- просадка FPS замедляет фильм целиком, но не рассинхронизирует камеру, частицы и субтитры;
- генератор случайных чисел `rng(seed)` — одинаковая картинка при каждом запуске.

Порядок кадра: `scene.update` → `cameraCtl.update` → `scene.lateUpdate` (всё, что зависит от камеры:
billboard-карточки, размер точек) → render.

## Как добавить сцену

```js
// src/scenes/AirportScene.js
export class AirportScene extends BaseScene {
  constructor(app) { super(app, { id: 'airport', duration: 25, feature: 'first_24h' }); }
  get requiredAssets() { return ['env.manas_airport', 'veh.airplane']; }   // ключи из манифеста
  build() { /* создать объекты, this.track(obj); cameraCtl.setPath({...}) */ }
  enter() { const tl = this.createTimeline(); this.app.cameraCtl.addToTimeline(tl, { duration: 25 }); /* … */ }
  lateUpdate(dt) { /* billboard и т.п. */ }
}
// src/main.js
app.scenes.register({ id: 'airport', create: (a) => new AirportScene(a), transition: 'matchCut' });
```

Для отсутствующих моделей сцена обязана иметь запасной вариант: `assets.instance(key)` вернёт `null`.

## Загрузка и память

- следующая сцена предзагружается, пока играет текущая; сборка (`build`) выполняется под «шторой» перехода,
  чтобы подвисания не были видны;
- `dispose()` сцены освобождает геометрии/материалы/текстуры, кроме общих ресурсов из кэша;
  `assets.release(keys)` освобождает кэш, когда ассет больше не нужен;
- ошибки: окно с понятным текстом вместо чёрного экрана; ассет не загрузился → предупреждение в консоли,
  сцена продолжает работать; потеря WebGL-контекста → сообщение «перезагрузите страницу».

## Ограничения, о которых нужно знать

- Скинированные (анимированные) модели нужно клонировать через `SkeletonUtils.clone` (уже в `vendor/`), а не
  `assets.instance()`, который делает обычный `clone(true)`.
- `AudioManager.play` декодирует файл при первом запуске — длинные треки лучше декодировать заранее в `preload`.
- `matchCut` пока безопасно деградирует до `dip` с одним предупреждением в консоли.
