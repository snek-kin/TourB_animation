# Библиотека ассетов

Источник правды — **`assets.manifest.json`**. Человекочитаемый реестр `ASSET_INVENTORY.md` генерируется из него
командой `npm run assets:report` (она же сверяет файлы с манифестом и проверяет бюджеты GLB).

## Структура

```
models/environment/   рельеф, города, здания, площади, аэропорт, озёра, горы
models/characters/    туристы, пешеходы
models/vehicles/      самолёт, автобусы, машины
models/objects/       чемоданы, монеты, интерьеры, рынок
textures/             текстуры; textures/ref/ — только референсы (в сцены не подключать)
hdri/                 небо и освещение (≤ 2K)
audio/ambient|sfx|music/
ui/                   логотип, иконки
effects/              LUT, шумы, атласы, спрайты для эффектов (процедурные эффекты живут в src/effects/)
```

Имена файлов: `snake_case`, латиница, без пробелов; модели — `.glb`; ключ в манифесте = `категория.имя`.

## Статусы

| Статус | Значение |
|---|---|
| **Available** | готовый файл лежит в проекте |
| **Prepared** | оптимизирован и готов к подключению к сцене (для процедурных — код написан и проверен) |
| **Placeholder** | временная замена; **в этой фазе не создавались намеренно** |
| **Missing** | файла нет; в реестре указан способ получения или создания |

## Как добавить ассет

1. Положите файл в нужную папку, 2. измените `status`/`file` записи в манифесте (путь `file` задаётся относительно
   `assets/`), 3. внесите источник и лицензию в `CREDITS.md`, 4. `npm run assets:report` — проверит наличие, размер и
   число треугольников. Загрузчик разрешает пути от корня приложения, включая GitHub Pages-подкаталог.

## Оптимизация GLB (команды проверены по `--help` gltf-transform 4.5.1)

```bash
npx gltf-transform inspect model.glb                      # статистика: треугольники, текстуры, размер
npx gltf-transform optimize in.glb out.glb --compress draco --texture-compress webp --texture-size 2048
```

- `--compress draco` — Draco-сжатие геометрии (декодер уже в `vendor/`, загрузчик подключается автоматически);
  альтернатива — `meshopt` (быстрее декодируется, нужен `MeshoptDecoder` — пока не подключён).
- `--texture-compress webp` уменьшает размер файла; `ktx2` уменьшает VRAM, но нужен KTX2Loader и транскодер Basis
  (в `vendor/` пока нет).
- `--simplify` / `--simplify-ratio` — упрощение геометрии под бюджет треугольников.

## Целевые бюджеты (ориентиры, не измерения)

| Тип | Треугольники | Текстуры | Файл |
|---|---|---|---|
| Рельеф/город (герой окружения) | ≤ 250–300 тыс. | ≤ 2048 | ≤ 10–12 МБ |
| Здания, площади, интерьеры | ≤ 40–80 тыс. | ≤ 2048 | ≤ 5–6 МБ |
| Транспорт | 3–25 тыс. | ≤ 1024–2048 | ≤ 1.5–3 МБ |
| Персонажи | ≤ 8 тыс. | ≤ 1024 | ≤ 2 МБ |
| Мелкий реквизит | ≤ 8 тыс. | ≤ 1024 | ≤ 2 МБ |

## Лицензии: правила

- Не использовать ассет, пока не записаны источник и лицензия (`CREDITS.md`).
- **CC0** — без атрибуции (всё равно записываем источник). **CC-BY** — обязательная атрибуция автора в титрах фильма.
- Платные модели — читать конкретную лицензию (например, «Extended Use») перед покупкой; не вшивать чужие логотипы.
- Данные Copernicus DEM — атрибуция обязательна при показе публике (формулировка в лицензии; начало: «produced
  using Copernicus WorldDEM-30 © DLR e.V.…»). OpenStreetMap — © OpenStreetMap contributors (ODbL).
- Не использовать Google Photorealistic 3D Tiles (кэширование и офлайн запрещены условиями Google).
