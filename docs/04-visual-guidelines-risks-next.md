# 04 · Визуальные правила, риски, следующая фаза

## Визуальные правила (Задача 6, предварительные)

**Свет и атмосфера.** Один источник «солнца» + полусфера неба; туман для глубины (в стенде `FogExp2`).
Общий тон сцен — холодный тёмно-синий из презентации (`navy #0a1e3c`), реалистичные сцены — дневные, тёплые.

**Цифровой акцент.** Зелёный `#35e08a` — только для цифрового слоя (дождь, частицы, маркеры). Не заливать им
реальные сцены; доля цифровых элементов в кадре — акцент, а не фон. Янтарный `#ffb03b` — вторичный акцент
(маркеры, бейджи «концепт»). Бренд-синий `#2f7bf6` — интерфейсные карточки.

**Свечение.** Аддитивные спрайты и шейдеры вместо тяжёлого bloom; не более одного сильного источника свечения
в кадре. Яркость дождя вблизи камеры гасится автоматически.

**Материалы и масштаб.** 1 единица = 1 метр. Окружение — спокойные PBR-материалы; интерфейсы — плоские,
без бликов. Человеческий масштаб проверять по метровой сетке стенда.

**Интерфейс.** Современный, чистый: скругления, брендовые цвета, системный шрифт (без загрузки из сети).
Любой текст в кадре — не мельче читаемого на проекторе (~24 px на 1080p).

**Камера.** Только плавные рельсы, без крена; ускорения ограничены сглаживанием; в кадре — не ближе 1.2 м
к объектам (коллайдеры). Переходы — по объектам (match cut), а не вспышкой/нарезкой.

**Честность кадра.** Каждая сцена с функцией — бейдж статуса; концепт — с пометкой «Концепт» прямо на карточке.

## Риски и ограничения

| Риск | Серьёзность | Что делать |
|---|---|---|
| **Нет ни одной реальной 3D-модели** (24 из 29 позиций реестра — Missing) | высокая | Phase 2 начинать с самого дешёвого: стилизованные модели + процедурные; сроки зависят от закупки/моделирования |
| Облёт гор по DEM 30 м выглядит мыльно вблизи | средняя | высота с дальнего плана + шумовая детализация + текстура; Copernicus GLO-30 — это поверхностная модель (DSM) |
| Модель Бишкека для превращения в карту требует отдельных мешей зданий | средняя | заложить при создании (OSM-экструзия даёт это бесплатно); платные модели проверить |
| Расхождение «бриф ↔ презентация» (переводчик, Smart Deals, живой город) | высокая для оценки проекта | решить до Phase 2 (см. `01-analysis.md`) |
| Музыка и лицензия на публичный показ | средняя | выбрать трек с явной лицензией до монтажа под него |
| Производительность на слабом ноутбуке/проекторе | средняя | адаптивное разрешение есть; **измерить на машине показа**; запасной план — записать фильм в видео из того же кода (`seek` + покадровый захват) |
| Safari/Firefox не проверялись | низкая–средняя | демонстрировать в Chrome/Edge |
| Google Photorealistic 3D Tiles как «готовый Бишкек» | — | **не использовать**: условия Google запрещают кэширование и офлайн |
| Утечки памяти при долгой работе | низкая | проверено: 10 циклов смены сцен без роста геометрий/текстур/программ/GSAP/DOM, `dispose` каждого эффекта (Phase 1.5, программный рендер); полный прогон 3:50 с профилем памяти на реальном железе — Phase 2 |
| Чужие данные в кадре (логотипы Booking, Yandex Go и т.п.) | средняя | не показывать как партнёров; если логотипы нужны — как «ссылки на сервисы» и без интеграционных визуальных метафор |

## Что нужно от вас

1. Решение по расхождениям (переводчик; сцены 7–8; Smart Deals — убрать или «Идея»).
2. Если есть существующий проект/HTML-презентация — приложить.
3. Логотип TourB (SVG) и правила его использования.
4. Целевая машина показа (ноутбук? проектор? разрешение) и нужен ли звук.
5. Желаемый язык фильма (RU/EN/оба) — влияет на субтитры и тексты на карточках.
6. Подтвердить, будете ли покупать модели (например, Бишкек) или делаем стилизованно.

## Рекомендация для Phase 2

Не начинать с самых красивых сцен — начать с того, что снимает больше всего риска:

1. **Раскадровка ключевых кадров + решение по расхождениям** (1–2 дня обсуждения, ноль кода).
2. **Смартфон + «вход в экран» + сборка интерфейса из частиц** — это ядро идеи и самый показательный эффект;
   использует готовые `ParticleMorph`/`MatrixRain`, не требует внешних моделей.
3. **Реальный `matchCut`** (приём A) на двух готовых объектах — докажет концепцию переходов.
4. Параллельно — закупка/создание минимального набора: самолёт, машины (Kenney Car Kit, CC0), DEM-рельеф.
5. Замер FPS на машине показа и корректировка бюджетов.

Облёт Кыргызстана и город-в-карту — Phase 3, когда будут рельеф и модель города.
